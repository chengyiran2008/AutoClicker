# 轻点 · 鼠标连点器（Windows）

白色简洁风格的图形界面连点器，**零第三方依赖**（仅 Python 标准库 tkinter + ctypes 调用 Win32 API）。

## 启动

**方式一（推荐）：双击 `AutoClicker.exe`** —— 已打包好的独立可执行文件，无需安装 Python，双击即用，无黑色控制台窗口。

**方式二：双击 `run.bat`**（需要本机 Python，无控制台窗口）

**方式三：命令行 `python main.py`**

> 说明：`AutoClicker.exe` 用 PyInstaller 打包（`--onefile --windowed`）。首次启动杀毒软件可能提示，属误报，放行即可。exe 首次运行需解压内置运行时，约 1~2 秒。配置 `config.json` 与诊断日志 `launch.log` 会生成在 exe 同目录。

要求：Windows + Python 3.10 以上，且 Python 安装时包含 tcl/tk（官方安装包默认包含）。

## 功能

### 实时信息

* 鼠标坐标实时刷新（60ms 一次）
* 光标处像素颜色实时预览 + HEX 值
* 本次运行的点击次数、触发次数统计

### 手动连点

| 参数  | 说明  |
| --- | --- |
| 鼠标按键 | 左键 / 右键 / 中键 |
| 点击方式 | 单击 / 双击 |
| 点击间隔 | 1 ~ 600000 毫秒，实测偏差 < 1%（已启用 1ms 系统定时器精度） |
| 随机浮动 | 间隔 ±0~90% 随机抖动，避免机械式等间隔 |
| 连点次数 | 无限连点 或 指定次数后自动停止 |
| 按下时长 | 按下与抬起之间的保持时间（部分程序需要 ≥10ms 才识别） |
| 启动延迟 | 启动后延迟若干秒再开始 |
| 点击位置 | 跟随鼠标当前位置 / 固定屏幕坐标（可用快捷键拾取） |

### 智能连点（屏幕颜色监测）

1. 点击「框选屏幕区域」→ 主窗口自动隐藏，全屏遮罩下拖拽出监测区域（Esc 取消）
2. 设置目标颜色：手动输入 HEX、「取区域当前色」或按快捷键吸取光标处颜色
3. 选择触发方式：
  * **匹配目标颜色时触发** —— 区域颜色变成目标色就点击（例：技能冷却结束变亮、按钮变为可点状态）
  * **偏离目标颜色时触发** —— 区域颜色离开目标色就点击
  * **颜色发生变化时触发** —— 以启动瞬间的颜色为基准，出现变化即点击（触发后自动重建基准）
4. 采样方式：
  * **区域平均色** —— 整块区域取平均，抗噪声，适合大色块
  * **区域内像素占比** —— 命中像素占比达到阈值才算满足，适合小图标/局部高亮
5. 触发动作：
  * **触发后连点 N 次** + 冷却时间 + 最多触发次数（0 为不限）
  * **条件满足期间持续连点** —— 条件一直成立就一直点，条件消失自动停手
6. 点击位置：监测区域中心 / 鼠标当前位置 / 指定坐标

其他参数：颜色容差 0~255（单通道最大允许偏差）、检测间隔（默认 100ms）。

### 全局快捷键（可自定义）

| 默认键 | 功能  |
| --- | --- |
| `F6` | 启动 / 停止连点（按当前选项卡决定手动或智能模式） |
| `F12` | 紧急停止 |
| `F7` | 拾取鼠标当前坐标，写入当前选项卡的坐标框 |
| `F8` | 吸取光标处颜色，写入智能连点的目标颜色 |

修改方式：在「全局快捷键」卡片点击对应按钮 → 直接按下新的按键（支持 Ctrl / Alt / Shift 组合），Esc 取消。快捷键在窗口最小化、失去焦点时同样生效，无需管理员权限（部分以管理员身份运行的程序内可能拦截，此时以管理员运行本程序即可）。

## 参数持久化

关闭窗口时自动把所有参数、监测区域、快捷键写入同目录 `config.json`，下次启动自动恢复。删除该文件即恢复默认。

## 自检

    python selftest.py

校验取色、区域采样、颜色判定、连点次数与间隔精度、智能触发逻辑与停止逻辑，**过程中不会产生任何真实点击**（点击动作被替换为计数器）。

## 目录结构

    autoclicker/
    ├── AutoClicker.exe    打包好的独立可执行文件（双击即用）
    ├── main.py            入口（DPI 感知 + 启动窗口）
    ├── run.bat            双击启动（需本机 Python）
    ├── selftest.py        逻辑自检
    ├── core/
    │   ├── winapi.py      ctypes 封装：DPI、坐标、SendInput 点击、按键状态、BitBlt 取色
    │   ├── hotkey.py      全局热键（GetAsyncKeyState 轮询 + 边沿触发 + 严格修饰键匹配）
    │   └── engine.py      连点引擎：手动连点、颜色监测智能触发、精确计时
    └── ui/
        ├── theme.py       白色主题 + DPI 缩放
        ├── widgets.py     卡片、按钮、色块、热键选择器、全屏框选
        └── app.py         主窗口与交互逻辑

## 重新打包 exe

    python -m PyInstaller --onefile --windowed --name AutoClicker main.py

产物在 `dist/`。修改源码后需重新打包；exe 与源码共用同一份 `config.json`（都生成在各自所在目录）。

## 使用建议

* 固定坐标模式会移动鼠标指针，运行中难以手动操作，务必记住紧急停止键 `F12`
* 智能连点时若点击位置落在监测区域内，可能因点击特效导致自触发，适当加大冷却时间
* 检测间隔越小 CPU 占用越高，一般 50~200ms 足够
* 连点间隔小于 5ms 时部分程序会丢弃事件，建议 ≥ 10ms
